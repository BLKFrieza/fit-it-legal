## About the App

Fit-it allows users to:

- Capture or upload garment photos
- Create local outfit boards in Regular Mode
- Generate mannequin pose outputs in Premium Mode

Regular Mode is local and deterministic.

Premium Mode may use Firebase and Google cloud services for AI image processing and generation.
